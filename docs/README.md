# Documentation

Start with the [CLI guide](cli.md) for commands and options. Use the [rule catalog](rules.md) to choose individual formatting rules.

| Guide | Contents |
| --- | --- |
| [CLI](cli.md) | Building, modes, options, exit codes, diagnostics, path discovery, and file writes. |
| [Rules](rules.md) | All 37 stable rule IDs, examples, and edit ownership. |
| [Formatting behavior](formatting.md) | Syntax coverage, preservation boundaries, warnings, and resource limits. |
| [Encoding](encoding.md) | UTF-8, UTF-16, CP932 conversion, BOMs, and line endings. |
| [Core API](api.md) | Internal Go entry points, options, results, and source ownership. |
| [Development](development.md) | Setup, source layout, standard checks, corpus audits, and optional runtime comparisons. |

Shell examples assume the repository root as the working directory. Normal builds and formatting do not require game data or an external runtime.
